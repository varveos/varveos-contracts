# ADR-0000: ADR 작성 규칙

- 상태: 채택 (2026-09-13)

## 맥락

아키텍처·규약·의존성(메이저) 변경은 근거가 남아야 이후에 되돌리거나 확장할 수 있다.

## 결정

- 파일명 `NNNN-제목.md`, 한글로 작성, 상태는 `제안 | 채택 | 폐기 | 대체됨(→ NNNN)`.
- 구성: 맥락 → 결정 → 결과(장점·단점·후속 작업).
- 대상: 계층 규칙 변경, 새 variant/토큰, 메이저 프레임워크 업그레이드, 데이터 모델 규약 변경, 외부 서비스 도입.
- ADR 없이 위 변경을 담은 PR은 반려한다.

## 결과

결정의 이력이 코드와 같은 저장소에 남는다. 문서 유지 비용은 PR당 몇 분 수준.
